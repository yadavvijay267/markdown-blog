# Screenshots

Screenshots go here. Take them after the first deploy:

1. `post-list.png` — the post list with tag chips and search.
2. `post-view.png` — a single post open, progress bar visible.
3. `editor.png` — the write-a-post editor with live preview side by side.
4. `mobile.png` — mobile view (390px wide).

Tip: in Chrome, DevTools → Device toolbar, or use `python3 -m http.server`
and screenshot the running page. Keep images under ~300 KB.
